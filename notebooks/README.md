# Notebooks

This folder contains a clean public-facing reproducibility notebook.

## Notebook

- `01_reproduce_manuscript_outputs.ipynb`

This notebook verifies and displays the final CSV outputs, manuscript-ready LaTeX tables, figures, and statistical significance results used in the manuscript.

The original exploratory Colab notebook contained repeated, failed, and non-linear execution cells created during development. It is not used as the main public reproducibility artifact. Instead, the repository provides cleaned source scripts, configuration files, final result CSVs, manuscript-ready tables, figures, and this inspection notebook.

Raw MovieLens datasets are not redistributed in this repository.
